# 軍人将棋（23枚型）― ブラウザで遊べる試作

友達とネット対戦できる「軍人将棋」の試作ゲームです。むずかしい準備はいりません。`index.html` をブラウザで開くだけで遊べます。

## 遊び方

### まず覚えること（目的）
- 相手の「総司令部」（相手の陣地の一番奥の列の、真ん中2マス）に、自分の将校（大将〜少尉のどれか）で入ると勝ちです。
- または、相手の「動かせる駒」を全部なくしても勝ちです（自分の番が来たときに動かせる駒が1つもないと、その人の負けです）。

### 盤と駒
- 盤は「6列 × 8行」です。手前の4行が自分の陣地、その奥の4行が相手の陣地です。
- 駒は1人23枚です。大将・中将・少将・大佐・中佐・少佐が1枚ずつ、大尉・中尉・少尉・飛行機・タンク・工兵が2枚ずつ、騎兵・スパイ・軍旗が1枚ずつ、地雷が2枚です。
- 自分の駒は名前が見えます。相手の駒は中身が見えず、色だけが見えます。

### 配置のしかた
1. 最初は自動でランダムに並んでいます。「🎲 ランダムに並べ直す」で何度でも並べ直せます。
2. 変えたいときは、自分の駒をタップして、もう1つの自分の駒をタップすると入れ替わります。空きマスをタップすると、そこへ動かせます。
3. 置き場所の決まりが2つあります。
   - 地雷と軍旗は、自分の陣地の一番前の列にある「突入口」（黄色い点線のマス）には置けません。
   - 軍旗は、自分の陣地の一番後ろの列には置けません。
4. 並べ終わったら「✅ 配置OK・準備完了」を押します。

### 駒の動き（前後左右だけ。ななめはダメ）
| 駒 | 動き |
|---|---|
| 将校（大将〜少尉）、スパイ | 1マス |
| タンク、騎兵 | 1〜2マス。途中のマスに駒があると、越えられません |
| 工兵 | まっすぐなら何マスでも。途中の駒は越えられません |
| 飛行機 | 前と後ろは、駒を飛び越えて何マスでも。横は1マスだけ |
| 地雷、軍旗 | 動かせません |

- 陣地と陣地の「境目」は、ふつうの駒は列の1番目と4番目（左から2列目と5列目）の「突入口」からしか越えられません。飛行機だけは、どこからでも越えられます。
- 動けるマスには黄色い丸、取れる相手の駒には赤い枠が出ます。

### 戦闘（相手の駒のマスに動くと戦闘）
- 将校同士は、階級が高い方が勝ちます（大将 ＞ 中将 ＞ 少将 ＞ 大佐 ＞ 中佐 ＞ 少佐 ＞ 大尉 ＞ 中尉 ＞ 少尉）。同じ種類同士は引き分けで、両方とも消えます。
- スパイは大将にだけ勝ち、それ以外には全部負けます。
- 飛行機は、将官（大将・中将・少将）に負けて、それ以外には勝ちます。
- タンクは、将官・飛行機・工兵に負けて、大佐以下や騎兵・スパイに勝ちます。
- 騎兵は、工兵とスパイにだけ勝ちます。
- 工兵は、タンク・スパイ・地雷に勝ちます。
- 地雷は動けませんが強い守りです。飛行機と工兵には負けますが、それ以外が攻めてきたら引き分け（地雷が爆発して、両方とも消えます）。
- 軍旗の強さは「軍旗の真後ろにある自分の駒」と同じになります。後ろに駒が無いと、一番弱くなります（どの駒にも負けます）。後ろの駒は、軍旗が負けても消えません。
- 戦闘になると、両方の駒が約1.5秒だけ見えるようになります。勝った駒は、また伏せられます。
- 勝てばそのまま相手のマスに進み、負ければ自分の駒だけが消え、引き分けは両方消えます。取った・取られた駒は、画面の下の一覧で確認できます。

## 友達とネット対戦する手順

ネット対戦は、2人のブラウザ同士が直接つながる仕組み（PeerJSという無料の仕組み）を使います。サーバーに登録したり、お金を払ったりする必要はありません。ただし、**2人ともネットにつながっていて、このページを開いている必要があります**。

1. **部屋を作る人**（先手・青・下側になります）
   - 「🌐 ネット対戦」を押して、「🏠 部屋を作る」を押します。
   - 6文字の「部屋コード」が出るので、それを友達に教えます（LINEなどで送ればOK）。
2. **部屋に入る人**（後手・橙になります）
   - 同じページを開いて「🌐 ネット対戦」を押し、教えてもらった6文字のコードを入れて「🚪 部屋に入る」を押します。
3. つながると、両方とも配置の画面になります。各自が配置して「✅ 配置OK・準備完了」を押すと、対戦が始まります。
4. あとは交互に駒を動かすだけです。戦闘の判定は両方の画面で同じ計算をして、結果を確かめ合います。
5. 接続が切れたら「🔄 再接続する」ボタンで、同じ部屋コードのまま作り直し／入り直しができます（対戦の途中だった場合は、配置からやり直しになります）。

### ページの置き場所
- このフォルダの `index.html` をパソコンやスマホのブラウザで直接開いても遊べます。
- 友達に渡しやすいのは、GitHub Pages のような「ホームページを置ける場所」にこのフォルダを置いて、そのアドレスを教えてもらう方法です。アドレスを開くだけで、2人とも同じページで遊べます。

## 同じ画面で2人対戦

- 「👥 同じ画面で2人対戦」を選ぶと、1台のスマホやパソコンを交互に持ち替えて遊べます。
- 配置のときと、毎回の手番の前に「相手に渡してください」という画面が出ます。相手が画面を見ていないときに「表示する」を押してください。

## この試作（v1）で簡単にしたところ

正直に書いておきます。

- **盤の形と突入口**: 本来の軍人将棋の盤はもっと複雑な形ですが、この試作では「6列×8行の四角い盤」と「境目を越えられるのは列1と列4だけ」という形に単純化しています。
- **戦闘の見せ方**: 本来は審判役の人が判定しますが、この試作ではコンピュータが判定し、戦闘のたびに両方の駒が約1.5秒見えます。勝った駒は、そのあとまた伏せられます（本来より少し情報が多く出ます）。
- **軍旗の扱い**: 「真後ろの駒と同じ強さ」という本来のルールを使っています。後ろの駒が地雷なら地雷と同じ判定になり、その地雷自体は残ります。
- **ネット対戦は「信頼ベース」です**: 相手の駒の中身は、戦闘が起きるまで相手の画面に送られません（駒の「位置」だけは、本物の将棋でも見えるので共有されます）。ただし、ブラウザ同士が直接つながる仕組みなので、悪いことをしようと思えば技術的には覗き見ができてしまいます。**知らない人との真剣勝負用ではなく、友達同士で楽しく遊ぶためのもの**として作っています。不正を防ぐ仕組みは入れていません。
- **総司令部に入ったときの勝ち**: 将校が相手の総司令部に「普通に動いて」入った場合は、動かした人の画面から勝ちを知らせます（これも信頼ベースです）。
- CPU（コンピュータ）との対戦は、今回の試作には入っていません。

## 動作に必要なもの

- ネット対戦: インターネット接続（対戦相手とつなぐため）。同じ画面での2人対戦は、ネットなしでも遊べます。
- 新しめのブラウザ（Chrome、Safari、Edgeなど）なら、そのまま動きます。ビルドなどの作業は不要です。
